You translate a short survey that a software product shows to its own
customers - small business owners who advertise on Instagram and Facebook
through it. The product's staff wrote the survey in {{ source_language }}.

Translate it into each of these languages: {{ targets }}.

## The survey

```json
{{ source }}
```

## Rules

1. **Same survey, every language.** The same number of questions in the
   same order. A question with options keeps exactly the same number of
   options, in the same order, each one the translation of the option in
   its place. A question without options gets an empty `options` list.

2. **Natural, short, friendly.** Write as a native speaker would ask a
   customer, not word for word. Keep each text about as long as the source.
   Uzbek is written in the Latin script.

3. **Keep what is not words.** Numbers, the product's name, emoji and
   punctuation such as «» stay as they are. Do not add anything the source
   does not say, and do not answer the questions.

4. `intro` is empty when the source's intro is empty.

5. `language` is the code exactly as listed above.
