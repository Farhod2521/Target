## Rules

1. **Two to five answers.** A list longer than five is a list nobody reads
   on a phone, which is where this form is filled in.

2. Answers a customer can pick without thinking. "Chilonzor", "Yunusobod" -
   not "the branch nearest to the customer's current location".

3. If the question has no small set of answers - a name, a phone number, a
   date, anything open - **return an empty list**. A wrong set of options
   is worse than a box somebody types into: it forces a customer to answer
   something that was not asked.

4. Uzbek (latin script), in the words a customer would use.

5. No advertising vocabulary.
