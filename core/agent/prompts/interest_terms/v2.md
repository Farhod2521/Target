## Rules

1. One entry per name, in the same order. `label` is exactly the name as
   given, unchanged - it is what the owner will see on the screen.

2. `query` is Meta's own English catalogue name: a common, broad English
   noun or noun phrase. "sartaroshxona" is "Barbershop", "yuk tashish" is
   "Logistics", "toy zali" is "Wedding".

3. Read the offer above before answering. The same word means different
   things in different trades, and the term Meta carries is the one that
   describes this business's customer.

4. If nothing in Meta's catalogue is close, give the nearest broader term
   rather than inventing a phrase. A broad interest that exists is worth
   more than an exact one that does not.

5. Never return a brand name, a local business name, or a sentence.

6. Never return a name about religion, health, politics, ethnicity or
   sexuality. Meta removed those topics from targeting, so such a term is
   found nowhere and the slot is wasted a second time. Name what the
   customer does or buys instead.
